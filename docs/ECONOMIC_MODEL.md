# Economic Model

## Company state
cash, receivables, payables, assets, liabilities, revenue, expenses, free cash flow, runway, reserves, business-unit P&L.

## Accounting
Use double-entry accounting.

Example customer payment:
Debit Cash; Credit Revenue/Receivable according to transaction type.

## Key metrics
- Revenue
- Gross margin
- Contribution margin
- Operating expenses
- Free cash flow
- Burn
- Runway
- CAC
- LTV
- Revenue per employee
- Revenue per creator
- Revenue per content asset
- Payback period

## Distress ladder
NORMAL → WARNING → COST_CONTROL → DISTRESS → EMERGENCY → LIQUIDATION → BANKRUPTCY.

## Capital allocation
Rank proposals by expected risk-adjusted economic value subject to liquidity constraints. The system must preserve an explicit reserve.
