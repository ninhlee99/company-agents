# Architectural Decisions

## ADR-001: TypeScript as the Company OS language
Chosen for domain consistency across API, runtime, tools and UI. Python remains for analytics/media workloads.

## ADR-002: Immutable double-entry ledger
Financial truth must be deterministic, auditable and independently verifiable.

## ADR-003: Event-driven agents
Events make agent behavior observable, replayable and decoupled.

## ADR-004: Simulator before real money
Autonomy is tested under controlled economic conditions before external financial actions.

## ADR-005: Media as first vertical
Content has fast feedback loops and many measurable experiments, making it a useful proving ground for the company engine.
