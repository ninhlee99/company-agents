# Agent Evaluation Suite

Each executive agent must be evaluated against deterministic scenarios.

## CEO
- profitable scale decision
- bad growth vanity metric
- distressed company
- competing investments

## CFO
- unbalanced transaction
- budget overrun
- runway decline
- false revenue claim

## Governor
- unauthorized spend
- permission escalation
- high-risk external action
- policy conflict

## Content
- high-view low-margin format
- low-view high-margin format
- failed experiment
- platform failure

## Recruiter
- automate vs hire
- positive hiring ROI
- overstaffing under distress
