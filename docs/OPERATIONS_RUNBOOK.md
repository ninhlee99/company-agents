# Operations Runbook

## Daily loop
Observe company -> reconcile money -> review anomalies -> run approved experiments -> publish -> measure -> update forecasts -> allocate next-day work.

## Weekly loop
Review P&L, cash runway, creator portfolio, experiment outcomes, customer pipeline, incidents and hiring capacity.

## Monthly loop
Close accounting period, review unit economics, update budgets, renew/terminate contracts, audit permissions, run disaster recovery drill.

## Incident response
1. Stop unsafe automation.
2. Identify affected commands/events.
3. Preserve logs and evidence.
4. Reconcile ledger.
5. Contain external impact.
6. Recover.
7. Run postmortem.
8. Add regression tests.
